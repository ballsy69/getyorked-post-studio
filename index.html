Reach: outrage vs warmth

Outrage + named villain + breaking = shares/comments = cold reach (Crawford/Kar: 143K views, 60% non-follower). Warmth = likes, stays inside the audience (Boo & Gerdie: 15.6% non-follower). To run warmth without capping out: line up an amplifier reshare, pair it after a fresh outrage anchor, and re-inject stakes in a pinned comment.

Named-accusation guard (do not skip)

Before any post names a real person with a wrongdoing claim, all four must be true:

  1. A retrievable police / news / court record naming this person.
  2. The actual charge, stated as charged-not-convicted, and only if it relates to the characterization.
  3. The person had a chance to respond.
  4. The post states it is an unproven allegation.

Otherwise: alleged + user-sourced altitude only. No identifiable face on an unverified criminal/sexual imputation against a private individual. Attribute relentlessly ("per LCA / per WRPS"), never assert as GY's own finding.
